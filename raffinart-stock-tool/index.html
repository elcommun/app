Raffinart 在庫更新ツール EL COMMUN

処理概要：「在庫CSV」のSKU末尾の品番コード（例: FIN-62604）をVol.3 / Vol.4の「品番」と照合し、総在庫数を更新します。
⬇️ オフライン版をダウンロード（ネット不要で使えます）
流れ

全体の流れ 作業マニュアル

1
Raffinart から在庫表をダウンロード
Raffinart ストックリスト から Vol.3 / Vol.4 の在庫表（xlsx）をダウンロード
2
GoQ System から在庫CSVをダウンロード
「在庫連携画面」で「rft-」で検索 → 【CSV】プルダウンで「EL COMMUN 楽天市場店」を選択 → 「すべて」にチェック → 「CSV出力」
3
このアプリで在庫データを更新 このアプリ
1と2のファイルをアップロードして「在庫データを更新する」を実行 → 更新後CSVをダウンロード
4
GoQ System へアップロード
「在庫連携画面」の「総在庫数」にある縦の三点リーダー（⋮）ボタンを押して、3で生成したファイルを「ファイルを選択」→「アップロード」
✓
差異商品を反映して終了
取り込み後、「EL COMMUN 楽天市場店」で「差異商品」を検索し、「反映」させて終了
1

在庫データをアップロード Vol.3 / Vol.4 （xlsx）

📥 ダウンロード元：Raffinart ストックリスト
  1. https://raffinart.jp/stock-list/ を開く
  2. 「INTERIOR STYLE Vol.3」 と 「INTERIOR STYLE Vol.4」 の在庫表（xlsx）をダウンロード
📊

Vol.3 と Vol.4 をまとめて選択できます

2つ同時にドロップ／選択 または クリックして選択（⌘キーで複数選択）
2

在庫CSVをアップロード itemdata_*.csv

📥 ダウンロード元：GoQ System
  1. 「在庫連携画面」を開き、「rft-」 で検索
  2. 上部の 【CSV】 プルダウンで 「EL COMMUN 楽天市場店」 を選択
  3. 「すべて」 にチェック → 「CSV出力」 ボタンを押す
📄

itemdata_*.csv（SKU, 総在庫数）

ドロップ または クリックして選択
更新

更新ルール

SKU末尾の品番コード（英大文字＋ハイフン＋数字）で Vol.3 / Vol.4 の「品番」と照合し、結果に応じて総在庫数を更新します。

照合結果総在庫数備考
「在庫状況」が ※ ・ X ・ △ 0 在庫切れ扱い
それ以外（空欄） 10 在庫あり扱い
品番が 未マッチ 0 実行後に一覧表示
「入荷予定」が SOLD OUT — 出力から除外し、実行後に一覧表示
SKUが rft- 以外 — Raffinart対象外のため出力から除外（在庫は変更されない）
3

実行

✅ 更新完了！

GoQ System「在庫連携画面」でCSVを取り込んだあと、「EL COMMUN 楽天市場店」で「差異商品」を検索し、「反映」させてください。
