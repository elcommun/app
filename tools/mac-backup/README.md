# Mac デスクトップ自動バックアップ（オフライン対応）

`app` の最新版を **Mac のデスクトップ**に保存し、**ネットが無くても開ける形**にして、更新があるたびに自動で入れ替える仕組み。

## 使い方（最初に1回だけ）
Mac の「ターミナル」に次の1行を貼って Enter:

```
curl -fsSL https://raw.githubusercontent.com/elcommun/app/main/tools/mac-backup/install.sh | bash
```

- デスクトップに **「app-backup」** フォルダができる → 中の `index.html` をブラウザで開く（トップの一覧。ID/パスワードは本番と同じ）
- 初回は約0.5GBの取得とライブラリのダウンロードで数分かかる
- 以後は **ログイン時と10分ごと**に GitHub を確認し、更新があれば自動で入れ替える（変更が無ければ何もしない）
- 更新したら通知センターに出る（失敗したときだけ）。経過は `~/.elcommun-app-backup/backup.log`
- 止めるとき: `bash ~/.elcommun-app-backup/repo/tools/mac-backup/uninstall.sh`（デスクトップのフォルダは消えない）

## フォルダ名を変えたいとき
- デスクトップの `app-backup` を**手で改名しない**（自動更新が元の名前に新しく作り直し、2つに増えてしまう）
- 名前を変えたいときは、ターミナルで `BACKUP_DEST="$HOME/Desktop/好きな名前"` を付けて `install.sh` を実行し直す。古いフォルダは手で捨てる
- 以前の名前（`EL COMMUNアプリ バックアップ`）で入れていた場合も、`install.sh` をもう一度実行すれば `app-backup` に切り替わる。古いフォルダは手で捨てる

## 仕組み
```
GitHub (main) ──git fetch──▶ ~/.elcommun-app-backup/repo   （全履歴つき。古い版もここに残る）
                                  │ rsync
                                  ▼
              ~/Desktop/app-backup/        （最新版。ネット無しで開ける形に加工）
```
- 「更新のたび」は GitHub から**定期的に確認**する方式（GitHub から Mac へ直接は送れないため。最大約10分の遅れ）
- `~/.elcommun-app-backup/repo` に全履歴があるので、デスクトップが最新版で上書きされても過去の版は取り出せる
- デスクトップのフォルダは**毎回 GitHub の内容で入れ替わる**。**このフォルダの中で直接編集・保存したものは消える**（作業データは別の場所に保存すること）

## オフライン対応でやっていること（`make-offline.py`）
- 外部ライブラリ（Excel/CSV 読み書き・React など。`cdnjs`／`jsdelivr`／`unpkg`）を初回にダウンロードして `_libs/` に保存し、読み込み先を書き換える
- Google Fonts の読み込みは外す → 文字は Mac 標準の日本語フォントで表示される（見た目が少し変わる）
- アプリ同士のリンク（`https://elcommun.github.io/app/◯◯/`）を、バックアップ内の `◯◯/index.html` に書き換える
- ライブラリの取得に失敗したら（ネット無しで初回実行など）、次回のチェックでやり直す。取得済みなら以後ネット無しで更新作業も不要

## できないこと・注意
- **Chrome で開くのがおすすめ。** Safari は `file://` の扱いが厳しく、ログイン画面などが動かないことがある（未確認）
- `file://` では、ブラウザの制限で**フォルダ内の別ファイルを読み込む機能**が動かないことがある（例: 楽天画像ダウンローダーが `supplier-ranking/data.js` を自動で読む部分。手動でファイルを選べば使える）
- アプリが画面に保存するデータ（アップロード済みの販売データ・欠品日など、ブラウザの `localStorage`）は、**本番のサイトとは別扱い**。バックアップ版には本番の保存データは引き継がれない
- バージョンの自動更新（本番での自動リロード）はバックアップ版では動かない（次の自動更新でフォルダごと入れ替わる）
- 本番サイトの**ログインはこのバックアップでは意味が無い**（デスクトップのファイルは誰でも開ける）。共有PCに置かないこと

## 権限（デスクトップに書き込めないとき）
macOS は、自動実行のプログラムがデスクトップに書くのを止めることがある。`backup.log` に「デスクトップに書き込めません」と出たら:
システム設定 → プライバシーとセキュリティ → **フルディスクアクセス** → `+` → `Cmd+Shift+G` で `/bin/bash` を入れて許可 → ターミナルで `bash ~/.elcommun-app-backup/bin/backup.sh`

## 保守メモ（Claude 向け）
- `install.sh` は `backup.sh` を `~/.elcommun-app-backup/bin/` にコピーして launchd から呼ぶ。`make-offline.py` は毎回 `repo/` の最新を使うので、これは自動で最新になる。`backup.sh` / `install.sh` を変えたら、ユーザーに install.sh の再実行を案内する
- 新しい外部ライブラリ（CDN）をアプリに追加しても、`make-offline.py` が自動で取り込む。ただし CDN のホストを増やすときは `CDN` の正規表現に足す
